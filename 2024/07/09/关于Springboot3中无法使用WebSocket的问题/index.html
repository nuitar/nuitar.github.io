关于Springboot3中无法使用WebSocket的问题

nuitar
  2024-07-09 11:46:51 2024-07-09 11:46:51 Created   2024-07-09 12:48 2024-07-09 12:48 Updated  
  • Java 
  • | 后端 
 

问题描述

SpringBoot3中创建websocket的bean实例，但是网页访问的时候却无法连接，后端显示找不到接口

解决方案

在Java中，从Spring Framework 5.0开始，Spring支持的WebSocket API已经从javax.websocket迁移到了jakarta.websocket。这个变化主要是由于Java EE（现在称为Jakarta EE）的规范和包名的迁移。

原因如下：

  1. Java EE到Jakarta EE的迁移：Java EE规范由Oracle移交给Eclipse基金会之后，Java EE被重命名为Jakarta EE。作为迁移的一部分，所有的包名从javax迁移到jakarta。

  2. 兼容性：新的Jakarta EE规范要求使用jakarta包名。为了与新的规范保持一致，Spring和其他依赖Jakarta EE的库也进行了相应的更新。

  3. 未来发展：Jakarta EE代表了未来的企业级Java标准。为了利用新的特性和改进，使用Jakarta命名空间是必要的。

因此，如果你使用Spring Boot 3或更高版本，并且需要使用WebSocket功能，你应该使用jakarta.websocket而不是javax.websocket。
